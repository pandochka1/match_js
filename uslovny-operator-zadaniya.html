Условный оператор

Практическое задание · Модуль 1 «Введение в JavaScript»

ПРАКТИЧЕСКОЕ ЗАДАНИЕ

Тема: Условный оператор · if / else / switch

Общая постановка задачи: для каждого задания выберите подходящий оператор ветвления — if / else или switch. Файл решения создайте сами. Запуск: node task.js. На вопросы под заданием отвечайте письменно, объясняя выбор оператора.

Задачи на if / else

1

Возрастная категория

лёгкая
Запросить у пользователя возраст и определить, кем он является: ребёнок (0–12), подросток (13–17), взрослый (18–59) или пенсионер (60+).
Подсказка
Используйте цепочку if / else if / else. Начните с самой младшей категории и проверяйте возраст по нарастающей.
Ответьте письменно
  1. Почему важен порядок проверок? Что будет, если сначала проверить «пенсионер»?
  2. Какое условие нужно для категории «взрослый»? Почему достаточно одной проверки?
2

Планета

лёгкая
Запросить название планеты. Если введено «Земля» или «земля» — «Привет, землянин!», иначе — «Привет, инопланетянин!».
Подсказка
Чтобы не проверять оба варианта регистра, приведите ввод к нижнему регистру через toLowerCase() и сравните с "земля".
Ответьте письменно
  1. Зачем нужен toLowerCase()? Какие ещё варианты ввода он «закрывает»?
  2. Что произойдёт, если пользователь введёт пустую строку?
3

Модуль числа

лёгкая
Запросить число и вывести его модуль (|7| = 7, |-7| = 7).
Подсказка
Модуль — число без знака: если число меньше нуля, берём отрицание. Можно решить через if или тернарный оператор.
Ответьте письменно
  1. Как выглядит тернарный оператор? В каких случаях его применяют?
  2. Запишите решение через if…else и сравните длину кода с тернарным вариантом.
4

Кратность 5

лёгкая
Запросить число и проверить, кратно ли оно 5. Вывести соответствующее сообщение.
Подсказка
Остаток от деления на 5 должен быть равен 0: n % 5 === 0. Строгое сравнение === обязательно.
Ответьте письменно
  1. Что возвращает оператор % ? Приведите пример для n = 12.
  2. Чем === отличается от ==? Почему здесь важно строгое сравнение?
5

Трёхзначное число

средняя
Запросить трёхзначное число и проверить, есть ли в нём одинаковые цифры. Например, 121 — есть, 123 — нет.
Подсказка
Цифры числа получите так: сотни = Math.floor(n / 100), десятки = Math.floor(n / 10) % 10, единицы = n % 10. Затем сравните попарно через логические операторы.
Ответьте письменно
  1. Объясните, как формула для десятков получает вторую цифру?
  2. Какой логический оператор (&& или ||) свяжет проверки равенства цифр и почему?
6

Високосный год

средняя
Запросить год и проверить, високосный ли он. Год високосный, если кратен 400 либо кратен 4 и не кратен 100.
Подсказка
Соберите условие одной строкой: (год % 4 === 0 && год % 100 !== 0) || (год % 400 === 0).
Ответьте письменно
  1. Проверьте вручную: 2000, 1900, 2024. Почему 1900 — не високосный?
  2. Какой приоритет у операторов && и || в составном условии?

Задачи на switch

1

Спецсимвол клавиши

лёгкая
Запросить число от 0 до 9 и вывести спецсимвол на этой клавише: 1→!, 2→@, 3→#, 4→$, 5→%, 6→^, 7→&, 8→*, 9→(, 0→).
Подсказка
Здесь 10 одинаковых по смыслу проверок одной переменной — используйте switch. Для символа '#' запишите '#' как строку. Не забудьте break в каждом case.
Ответьте письменно
  1. Почему switch удобнее, чем 10 проверок if?
  2. Что произойдёт, если в одном из case забыть break?
  3. Что выведет default для числа 12?
2

Конвертер валют

средняя
Пользователь вводит количество USD и выбирает валюту: EUR, UAN или AZN. Вывести полученную сумму. Курсы задайте сами.
Подсказка
Сравнение выбранной валюты — три варианта одной переменной, удобно switch. В каждом case умножайте сумму на соответствующий курс.
Ответьте письменно
  1. Какую роль выполняет default в switch?
  2. Что будет, если пользователь введёт валюту, которой нет в списке?
  3. Где удобнее хранить курсы — в switch или в объекте? Почему?

Требования: для ввода — prompt(), для вывода — console.log(). Каждая задача — отдельная функция в одном файле. Названия переменных осмысленные.
