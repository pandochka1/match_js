Теория

Логические типы: Boolean learn.javascript.ru/logical-operators

Программа — это череда решений. Каждое решение сводится к одному вопросу: true (истина) или false (ложь)? Именно так компьютер понимает, что делать дальше: выполнить один фрагмент кода или другой.

Тип Boolean имеет всего два значения:

let isLoggedIn = true;
let isAdmin = false;

Откуда берутся true и false?

Булевы значения появляются в трёх случаях:

  • Результат сравнения — 5 > 3 даёт true, а 10 === "10" — false
  • Приведение типа — любое значение можно явно превратить в Boolean через Boolean(x)
  • Неявное приведение в условии — if (x) само приводит x к boolean

Неявное приведение — частая неожиданность для начинающих. Когда вы пишете if (x), JavaScript смотрит: является ли x «истинным» (truthy) или «ложным» (falsy)? Всего существует ровно 6 falsy-значений. Всё остальное — truthy.

ЗначениеBoolean(x)Falsy?
falsefalseда
0falseда
"" (пустая строка)falseда
nullfalseда
undefinedfalseда
NaNfalseда
Любое число кроме 0trueнет
Любая непустая строкаtrueнет
Любой объект (даже {})trueнет

Запомните 6 falsy-значений: false, 0, "", null, undefined, NaN. Это пригодится в каждой второй проверке.

Кибербезопасность
Путаница между false и falsy-значениями — частый источник багов. Например, if (user.role) не отличит строку "" от undefined — оба falsy. В проверках прав доступа всегда используйте явные сравнения, а не truthy-проверку.
Операторы сравнения learn.javascript.ru/comparison

Операторы сравнения — это инструмент, которым вы будете пользоваться в каждом втором условии. Результат сравнения всегда true или false.

Полный список

a > b    //  больше
a < b    //  меньше
a >= b   //  больше или равно
a <= b   //  меньше или равно
a == b   //  равно (с приведением типов)
a === b  //  строго равно (без приведения)
a != b   //  не равно
a !== b  //  строго не равно

Строгое vs нестрогое сравнение

Ключевое различие: == перед сравнением приводит оба операнда к одному типу, а === — нет. Это порождает неочевидные результаты:

  • 5 == "5" → true (строка стала числом)
  • 5 === "5" → false (разные типы: number vs string)
  • 0 == false → true
  • 0 === false → false
  • "" == false → true

Сравнение строк

Строки сравниваются посимвольно (лексикографически, по Unicode-кодам):

  • "a" < "b" → true
  • "apple" < "banana" → true
  • "5" > "15" → true! Потому что сравниваются первые символы: '5' (код 53) vs '1' (код 49)

Последний пример — классическая ловушка: строковое сравнение чисел даёт неверный результат. Если вы сравниваете числа — убедитесь, что оба операнда числа, а не строки.

Сравнение с NaN и null

NaN (Not-a-Number) — единственное значение в JS, которое не равно самому себе:

NaN === NaN  // false! Никогда так не проверяйте.
// Используйте isNaN(x) или Number.isNaN(x)

null ведёт себя особо: он равен только undefined через ==, но не через ===:

null == undefined   // true
null === undefined  // false

Правило профессионала: всегда используйте === и !==. Единственное легитимное исключение — проверка if (x == null), которая ловит и null, и undefined одновременно.

Кибербезопасность
В системах аутентификации == может дать ложно-положительный результат. Например, 1 == true — true. Если сессионный ключ — число 1, а код ожидает true, возможна подмена. Только строгое === гарантирует безопасность.
Условный оператор if / else learn.javascript.ru/ifelse

Конструкция if — главный инструмент ветвления. Если условие truthy — выполняется блок, если falsy — пропускается.

Базовая форма

let age = 18;

if (age >= 18) {
  console.log("Доступ разрешён");
}

С else и else if

let hour = 14;

if (hour < 12) {
  console.log("Доброе утро");
} else if (hour < 18) {
  console.log("Добрый день");
} else {
  console.log("Добрый вечер");
}

Цепочка работает последовательно: первое истинное условие выполняет свой блок и завершает всю конструкцию. Остальные проверки пропускаются. Это важно помнить: порядок условий имеет значение.

Вложенные if

Условия можно вкладывать друг в друга. Но старайтесь не делать глубже 2–3 уровней — код становится нечитаемым:

if (user) {
  if (user.role === "admin") {
    console.log("Полный доступ");
  } else {
    console.log("Ограниченный доступ");
  }
} else {
  console.log("Не авторизован");
}

Особенности приведения в условии

Любое выражение в скобках if (...) приводится к boolean. Поэтому можно писать лаконичные проверки:

let name = "";
if (!name) {
  console.log("Имя не указано");  // "" — falsy, !"" → true
}

let items = [];
if (items.length) {
  console.log("Есть элементы");   // 0 — falsy, блок не выполнится
}

Но будьте осторожны: if (items.length) не выполнится при 0 элементах. Если 0 — допустимое значение, проверяйте явно: if (items.length > 0).

Тернарный оператор ? :

Когда нужно выбрать одно из двух значений в одной строке:

let access = user.isAdmin ? "полный" : "ограниченный";

// То же самое через if:
// let access;
// if (user.isAdmin) access = "полный";
// else access = "ограниченный";

Тернарный оператор — это выражение, возвращающее значение. Его можно использовать внутри console.log, при присваивании и в шаблонных строках. Не злоупотребляйте вложенными тернарниками — они сильно ухудшают читаемость.

Кибербезопасность
Типичный паттерн: if (failedAttempts >= MAX_ATTEMPTS) { account.lock(); }. Пороговые значения (MAX_ATTEMPTS) всегда выносят в константы — их легче менять и тестировать. Никогда не используйте магические числа в условиях.
Логические операторы learn.javascript.ru/logical-operators

Три оператора для работы с булевыми значениями. Особенность JS в том, что && и || не всегда возвращают true/false — они возвращают одно из исходных значений.

И (AND) — &&

Вычисляет операнды слева направо. Как только встречает falsy — останавливается и возвращает его. Если все truthy — возвращает последнее:

true && true    // true
true && false   // false
false && true   // false (дальше не идёт — короткое замыкание)
5 && "hello"    // "hello" (оба truthy, вернулся последний)
null && "ok"    // null (первый falsy — остановка)

ИЛИ (OR) — ||

Тоже идёт слева направо. Как только встречает truthy — останавливается и возвращает его. Если все falsy — возвращает последнее:

true || false   // true (дальше не идёт)
false || 42     // 42
0 || "" || 100  // 100 (первый truthy)
null || 0       // 0 (все falsy, вернулось последнее)

НЕ (NOT) — !

Просто инвертирует: !true → false, !false → true. Часто используется для проверки «не равно»:

let isBlocked = false;
if (!isBlocked) {
  console.log("Можно войти");
}

let name = "";
if (!name) {
  console.log("Имя не указано");
}

Приоритет (важно!)

Порядок обработки: ! → && → ||. Скобки — выше всего:

true || false && false
// && выше по приоритету: false && false → false
// потом: true || false → true

(true || false) && false
// Скобки изменили порядок: true || false → true
// потом: true && false → false

Совет: если условие сложнее трёх операндов — ставьте скобки. Код пишется для людей, а не для интерпретатора.

Кибербезопасность
Логические операторы — основа правил обнаружения атак. «Сработать, если больше 5 попыток И пользователь не заблокирован» — это attempts > 5 && !isBlocked. IDS/IPS системы компилируют такие правила в код, аналогичный этому.
Конструкция switch learn.javascript.ru/switch

Когда нужно сравнить одну переменную с множеством возможных значений, switch читается значительно легче, чем длинная цепочка if-else if.

Синтаксис

let role = "editor";

switch (role) {
  case "admin":
    console.log("Полные права");
    break;
  case "editor":
    console.log("Может редактировать");
    break;
  case "viewer":
    console.log("Только чтение");
    break;
  default:
    console.log("Роль не распознана");
}

Важно про break

Если забыть break — выполнение «провалится» в следующий case независимо от его условия. Это называется fall-through:

switch (2) {
  case 1:
    console.log("Один");   // не выполнится
  case 2:
    console.log("Два");    // выполнится
  case 3:
    console.log("Три");    // И ЭТО ТОЖЕ! Нет break
}
// Вывод: "Два", "Три"

Иногда fall-through используют осознанно — для группировки case:

switch (code) {
  case 400:
  case 403:
  case 404:
    console.log("Ошибка клиента");
    break;
  case 500:
  case 502:
  case 503:
    console.log("Ошибка сервера");
    break;
}

switch(true) — приём для условий

Вместо конкретного значения можно передать true, а в каждом case написать условие:

switch (true) {
  case score >= 90:
    grade = "отлично";
    break;
  case score >= 70:
    grade = "хорошо";
    break;
  case score >= 50:
    grade = "удовлетворительно";
    break;
  default:
    grade = "неудовлетворительно";
}

Такой подход не хуже if-else по читаемости и выглядит более структурированным.

Когда выбрать switch: когда сравниваете одну переменную с 3+ конкретными значениями (строки или числа). Для диапазонов (например, if (age > 18)) лучше использовать if-else.

Примеры с пошаговым разбором

Пример 1

Определение знака числа (IF)

Запросить у пользователя число и определить, оно положительное, отрицательное или ноль. Используем if / else if / else.
Как это работает: конструкция if проверяет первое условие. Если число больше нуля — сразу возвращаем «положительное». Если нет — проверяем второе условие: меньше ли нуля? Если и это не сработало — остаётся только вариант «ноль». Порядок проверок важен: более специфичные условия должны быть раньше. Оператор > 0 — это сравнение, он возвращает true или false. 
function signOfNumber(n) {
  if (n > 0) {
    return "положительное";
  } else if (n < 0) {
    return "отрицательное";
  } else {
    return "ноль";
  }
}
Пример 2

Координатная четверть (вложенный IF)

Запросить координаты точки (x, y) и определить номер четверти. Учесть случаи попадания на оси X, Y или в начало координат.
Как это работает: координатная плоскость делится на 4 четверти. Сначала обрабатываем особые случаи: если обе координаты равны нулю — точка в начале координат. Затем проверяем попадание на оси (одна координата равна нулю). И только после этого — четверти, комбинируя знаки x и y через &&. Чем раньше находится особый случай, тем меньше проверок нужно. 
function quadrant(x, y) {
  if (x === 0 && y === 0) {
    return "начало координат";
  } else if (x === 0) {
    return "на оси Y";
  } else if (y === 0) {
    return "на оси X";
  } else if (x > 0 && y > 0) {
    return "I четверть";
  } else if (x < 0 && y > 0) {
    return "II четверть";
  } else if (x < 0 && y < 0) {
    return "III четверть";
  } else {
    return "IV четверть";
  }
}
Кибербезопасность
Вложенные условия — типичный паттерн для многоуровневых проверок безопасности: «если запрос пришёл из доверенной сети И если метод POST И если тело не пустое — обработать».
Пример 3

Калькулятор (SWITCH)

Пользователь вводит 2 числа и знак (+ - * /). Реализовать вычисление через switch.
Как это работает: switch принимает переменную op и ищет среди case подходящее значение. Если находит "+" — выполняет сложение, для "/" — перед делением проверяет, не равен ли делитель нулю. Если ни один case не совпал — срабатывает default. Обратите внимание на break: в этом примере он не нужен, потому что внутри каждого case стоит return, который завершает функцию целиком. 
function calc(a, op, b) {
  switch (op) {
    case "+":
      return a + b;
    case "-":
      return a - b;
    case "*":
      return a * b;
    case "/":
      if (b === 0) return "ошибка: деление на 0";
      return a / b;
    default:
      return "неизвестная операция";
  }
}
Пример 4

Большее из двух чисел (тернарный)

Запросить 2 числа и вывести большее из них, используя тернарный оператор ? :.
Как это работает: тернарный оператор проверяет условие a > b. Если true — возвращает a, если false — возвращает b. Вся конструкция — это выражение, которое возвращает значение, поэтому её можно использовать прямо в return. Для сравнения: та же логика через if заняла бы 4 строки вместо одной. 
function maxOfTwo(a, b) {
  return a > b ? a : b;
}

Задачи для самостоятельной работы

10 задач разного уровня. Выберите подходящий оператор ветвления: if / switch / тернарный. Код задач в файл script.js не включён — пишите всё самостоятельно.

1

Возрастная категория

лёгкая
Запросить у пользователя его возраст и определить, кем он является:
• ребёнок (0–12)
• подросток (13–17)
• взрослый (18–59)
• пенсионер (60+)
Используйте if / else if / else.
2

Спецсимвол клавиши

лёгкая
Запросить у пользователя число от 0 до 9 и вывести спецсимвол, расположенный на этой клавише:
1 → !, 2 → @, 3 → #, 4 → $, 5 → %, 6 → ^, 7 → &, 8 → *, 9 → (, 0 → )
Используйте switch.
3

Модуль числа

лёгкая
Запросить у пользователя число и вывести его модуль: |7| = 7, |-7| = 7.
Используйте тернарный оператор.
4

Кратность 5

лёгкая
Запросить 1 число и проверить, кратно оно 5 или нет. Вывести соответствующее сообщение.
Используйте тернарный оператор.
5

Трёхзначное число

средняя
Запросить у пользователя трёхзначное число и проверить, есть ли в нём одинаковые цифры.
Подсказка: получите цифры через Math.floor(n / 100), Math.floor(n / 10) % 10, n % 10.
6

Високосный год

средняя
Запросить у пользователя год и проверить, високосный он или нет.
Правило: год високосный, если кратен 400, ИЛИ кратен 4 и при этом не кратен 100.
Используйте логические операторы && и ||.
7

Конвертер валют

средняя
Пользователь вводит количество USD и выбирает, в какую валюту перевести: EUR, UAN или AZN.
Курсы: EUR = 0.92, UAN = 41.15, AZN = 1.70 (условно).
Используйте switch или объект.
8

Палиндром

сложная
Запросить у пользователя пятиразрядное число и определить, является ли оно палиндромом (читается одинаково слева направо и справа налево).
Пример: 12321 → да, 12345 → нет. Получите цифры через остаток от деления.
9

Скидка на покупку

средняя
Запросить у пользователя сумму покупки и вывести сумму к оплате со скидкой:
• от 200 до 300 → скидка 3%
• от 300 до 500 → скидка 5%
• от 500 и выше → скидка 7%
• до 200 → скидки нет
Верните объект { percent, final }.
10

Дата: следующий день

сложная
Запросить дату (день, месяц, год) и вывести следующую за ней дату. Учтите:
• переход на следующий месяц (30→31 число)
• переход на следующий год (31 декабря)
• високосный год (февраль 29 дней)
Проверьте корректность введённой даты.
Кибербезопасность
Манипуляции с датами — частый вектор атак. Проверка корректности даты в логах, токенах и сертификатах — обязательная часть security-аудита.
