Теория

Что такое цикл learn.javascript.ru/while-for

В программировании часто требуется повторить одно и то же действие несколько раз. Программные механизмы, позволяющие несколько раз выполнить один и тот же блок кода, называют циклами.

Повторяемый блок кода называется телом цикла (loop body), а процесс его выполнения — итерацией (iteration). Фраза «на второй итерации» означает «при втором повторе тела цикла».

Повтор происходит в зависимости от некоторого выражения — циклового условия (loop condition). Если условие истинно — цикл повторяется; если ложно — прекращается.

Если циклового условия нет — повторения не прекращаются, получается бесконечный цикл. Он выполняется в течение всей работы сценария и прерывается только после его завершения. Бесконечные циклы применяются для постоянного мониторинга параметров (например, сетевой активности), поддержания анимации или пользовательского ввода в играх. С негативной стороны — бесконечный цикл в результате ошибки программиста приводит к «зависанию» сценария.

Если в цикле необходим подсчёт номера итерации, вводится отдельная переменная — цикловая переменная (счётчик). Она принимает значение, равное номеру повтора, и изменяется с каждым шагом. Величина, на которую изменяется цикловая переменная, называется шагом (step).

Классификация циклов виды и выбор

По способу организации повторного выполнения кода циклы делят на:

  • Циклы-счётчики — выполняются заданное количество раз. Количество повторов известно до начала цикла.
  • Условные циклы — выполняются, пока некоторое условие истинно. Количество повторов заранее неизвестно.

Условные циклы, в свою очередь, делятся на:

  • Циклы с предусловием — условие проверяется до выполнения тела. Могут не выполниться ни разу, если условие изначально ложно.
  • Циклы с постусловием — условие проверяется после выполнения тела. Выполняются, по крайней мере, один раз.

  • Знаете заранее число повторов → for
  • Число повторов неизвестно, но может быть 0 → while
  • Действие нужно выполнить хотя бы один раз, а потом повторять → do…while
Цикл while (предусловие) learn.javascript.ru/while-for

Цикл с предусловием создаётся оператором while. Общий синтаксис:

while (condition) {
  // тело цикла
}

Цикл обеспечивает повторное выполнение тела, пока условие остаётся истинным. Перед каждой итерацией условие проверяется заново.

Для того чтобы цикл имел окончание, в теле цикла должны быть инструкции, влияющие на условие повторения. Иначе — бесконечный цикл. Это одна из самых популярных ошибок даже у опытных программистов: забыть включить в тело инструкции по управлению условием.

Правильный вариант — цикл завершится

let i = 1;
while (i < 10) {
  console.log(i);
  i++;          // увеличиваем i — условие когда-нибудь станет ложным
}
// Вывод: 1 2 3 4 5 6 7 8 9

Неправильный вариант — бесконечный цикл

let i = 1;
while (i < 10) {
  console.log(i);
  // i++ забыли! i всегда равно 1, условие всегда true
}
// Зависание: вкладка перестанет отвечать

В первом случае переменная i увеличивается на каждой итерации и рано или поздно перестаёт удовлетворять условию i < 10. Во втором случае i навсегда остаётся равной 1 — условие всегда истинно, и цикл выполняется бесконечно. Это не синтаксическая ошибка: такой код скомпилируется и запустится, но программа «зависнет».

Когда применять while:

  • заранее неизвестно количество повторов тела цикла
  • условие окончания не зависит напрямую от цикловой переменной
  • цикл зависит от входящих данных, например от действия пользователя
Цикл do…while (постусловие) learn.javascript.ru/while-for

Цикл с постусловием создаётся оператором do…while:

do {
  // тело цикла
} while (condition);

В отличие от while, условие проверяется после выполнения тела. Поэтому цикл с постусловием выполнится как минимум один раз, даже если условие изначально ложно.

Циклы с постусловием удобно применять, когда тело должно быть выполнено хотя бы один раз — например, запрос ввода у пользователя до получения корректного значения.

let answer;
do {
  answer = prompt("Введите yes или no");
} while (answer !== "yes" && answer !== "no");

Другой пример — получение двух случайных чисел, не равных между собой. Второе число нужно рассчитать как минимум один раз, а при совпадении с первым — рассчитывать повторно:

let x1 = Math.random();
let x2;
do {
  x2 = Math.random();
} while (x2 === x1);

Ошибка бесконечного цикла в do…while

Как и в while, в теле do…while должно что-то меняться, чтобы условие когда-нибудь стало ложным. Сравните:

// Верно: переменная меняется, цикл завершится
let n = 100;
do {
  console.log(n);
  n = Math.floor(n / 2);   // n уменьшается
} while (n > 0);
// Вывод: 100 50 25 12 6 3 1
// Неверно: n не меняется — бесконечный цикл
let n = 100;
do {
  console.log(n);
  // нет инструкции, меняющей n!
} while (n > 0);
// Зависание

Разница в одной строке: если в теле цикла нет инструкции, влияющей на условие, цикл никогда не завершится. В do…while это особенно коварно, потому что хотя бы одна итерация всегда выполняется, и ошибка проявляется не сразу.

Цикл for (счётчик) learn.javascript.ru/while-for

Цикл-счётчик организуется оператором for. Синтаксис содержит три блока:

for (initialization; condition; expression) {
  // тело цикла
}
  • initialization — инициализация цикловой переменной. Выполняется один раз перед началом цикла.
  • condition — условие, при котором цикл продолжается. Проверяется перед каждой итерацией.
  • expression — изменение цикловой переменной. Выполняется после каждой итерации.

Типичная запись:

for (let i = 0; i < 5; i++) {
  console.log(i);   // 0 1 2 3 4
}

Традиционно цикловую переменную называют i (от англ. iteration), но это необязательно — можно выбрать любое имя.

Порядок работы:

  • 1. Выполняется блок инициализации (один раз)
  • 2. Проверяется условие. Если true — выполняется тело
  • 3. Выполняется блок изменения переменной
  • 4. Снова проверяется условие…

for — это разновидность цикла с предусловием: если условие изначально ложно (например, i < 0), тело не выполнится ни разу.

Все три блока могут быть пустыми (но не разделители «;»). Например, если переменная инициализирована до цикла:

let i = 0;
for (; i < 5; i++) {
  console.log(i);
}

Блоки могут содержать несколько операций через запятую:

for (let i = 0, j = 10; i !== j; i++, j--) {
  console.log(i, j);
}

Им можно заменить любой условный цикл, но лучше использовать for по назначению — для циклов-счётчиков с известным числом повторов. Это вопрос читаемости кода.

Типичная ошибка: забытый шаг

Как и в while, в for можно забыть изменить цикловую переменную — если убрать третий блок или не менять переменную в теле:

// Верно: третий блок есть — цикл завершится
for (let i = 0; i < 5; i++) {
  console.log(i);
}

// Неверно: третий блок пуст, i не меняется — бесконечный цикл
for (let i = 0; i < 5; ) {
  console.log(i);
  // i++ нет!
}

Однако, если i++ перенесён в тело, цикл всё равно работает — лишь бы переменная менялась. Главное правило: что-то в цикле должно гарантированно приближать условие к ложному.

for…in и for…of learn.javascript.ru/for-in

Для перебора содержимого массивов и коллекций предназначены сокращённые формы оператора for:

for (variable in object)   // перебор индексов (ключей)
for (variable of object)   // перебор значений

for…in перебирает ключи (индексы) объекта, for…of — значения. Проще всего пояснить разницу на примере:

let arr = [5, 4, 3, 2, 1];

for (let i in arr) console.log(i);      // 0 1 2 3 4 (индексы)
for (let v of arr) console.log(v);      // 5 4 3 2 1 (значения)

Детальнее массивы и объекты изучаются в следующих темах, но знать о существовании этих циклов важно уже сейчас.

break, continue, метки learn.javascript.ru/while-for

Для дополнительного управления выполнением цикла предназначены операторы break и continue. Они применимы во всех циклах.

break — полная остановка

break полностью останавливает выполнение цикла, независимо от состояния условия. Применяется при появлении недопустимого значения или условия, не позволяющего продолжать:

for (let i = 0; i < 10; i++) {
  let r = Math.round(Math.random() * 6) + 1;
  if (r === 4) break;     // выпала четвёрка — стоп
  console.log(r);
}

continue — остановка итерации

continue останавливает выполнение текущей итерации и переходит к следующей (если условие позволяет). Полезно для пропуска нежелательных данных:

for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) continue;   // пропускаем чётные
  console.log(i);              // 1 3 5 7 9
}

Метки (labels)

Вложенные циклы можно прерывать целиком с помощью меток. Метка — идентификатор с двоеточием перед циклом:

outer: for (let i = 0; i < 5; i++) {
  for (let j = 0; j < 5; j++) {
    console.log(i, j);
    if (j === 3) break outer;   // прерываем внешний цикл
  }
}

Метки можно использовать и с continue.

Примеры с пошаговым разбором

Пример 1

Кредитный калькулятор (while)

Пользователь берёт кредит: сумма, ежемесячная ставка и платёж. Определить, за сколько месяцев долг будет погашен. Количество повторов заранее неизвестно — используем while.
Как это работает: мы оказались в ситуации, когда число повторов заранее неизвестно — оно зависит от суммы кредита, ставки и платежа. Поэтому цикл-счётчик (for) не подходит, нужен условный цикл while.
Условие: amount > 0 — пока есть непогашенный долг, цикл продолжается. Как только долг становится нулевым или отрицательным — условие ложно, цикл прекращается.
Тело цикла: на каждой итерации (каждом месяце) долг сначала растёт на процентную ставку (amount += amount * rate / 100), затем уменьшается на платеж (amount -= payment). Счётчик months++ отслеживает число итераций — это гарантирует, что переменная меняется, и цикл не станет бесконечным.
Если платеж меньше начисленных процентов: долг будет расти каждый месяц, условие amount > 0 всегда истинно — цикл станет бесконечным. Это пример осмысленной ошибки в данных, а не в коде. 
function creditMonths(amount, rate, payment) {
  let months = 0;
  while (amount > 0) {
    amount += amount * rate / 100;
    amount -= payment;
    months++;
  }
  return months;
}
Пример 2

Два разных случайных числа (do…while)

Получить два случайных числа в заданном диапазоне, не равных между собой. Второе число нужно рассчитать как минимум один раз — используем do…while.
Как это работает: мы не знаем заранее, с какой попытки выпадут два разных числа. Это может случиться с первой же итерации, а может потребовать десятка повторов. Поэтому количество итераций неизвестно — используем условный цикл.
Почему do…while, а не while: второе число нужно получить как минимум один раз — нельзя сравнивать то, чего нет. do…while сначала генерирует число, а потом проверяет, не совпало ли оно с первым. while тоже подошёл бы, но потребовал бы дублирования кода генерации до цикла.
Условие: x2 === x1 — если числа равны, повторяем генерацию. Как только числа оказываются разными — цикл прекращается. Обратите внимание: условие сформулировано «повторять, пока равны», а не «пока не равны». Это типичная логика для постусловия. 
function randomPair(a, b) {
  let x1 = Math.floor(Math.random() * (b - a + 1)) + a;
  let x2;
  do {
    x2 = Math.floor(Math.random() * (b - a + 1)) + a;
  } while (x2 === x1);
  return [x1, x2];
}
Пример 3

Таблица умножения (for)

Вывести таблицу умножения для заданного числа от 1 до 10. Число повторов известно заранее (10) — используем for.
Как это работает: число повторов известно заранее — ровно 10 строк таблицы. Это классический случай для цикла-счётчика for.
Три блока цикла: инициализация let i = 1 выполняется один раз перед началом; условие i <= 10 проверяется перед каждой итерацией; шаг i++ выполняется после тела. Условие использует нестрогое сравнение <=, потому что число 10 само должно попасть в таблицу.
Условие задачи: нам нужно ровно 10 чисел, но числа, кратные 4, мы пропускаем. Сколько всего итераций потребуется — неизвестно (зависит от случайности), поэтому for с фиксированным числом повторов не подходит — используем while.
Условие цикла: result.length < 10 — продолжаем, пока в массиве не наберётся 10 подходящих чисел. Как только массив заполнен — условие ложно, цикл завершается.
Роль continue: когда случайное число делится на 4 (r % 4 === 0), срабатывает continue — оставшаяся часть тела (result.push(r)) пропускается, и цикл переходит к следующей итерации. Без continue пришлось бы оборачивать push в условие if, что менее наглядно.
Возможная ошибка: если continue стоит, но забыт result.push в ветке «не кратно 4» — массив никогда не заполнится, и цикл станет бесконечным. Всегда проверяйте, что условие выхода действительно достигается на каждой итерации.
Почему не while: можно было бы написать let i = 1; while (i <= 10) { …; i++; }, но for собирает все три части управления циклом в одной строке — код читается лучше, и вероятность забыть i++ (и получить бесконечный цикл) ниже. 
function multiplyTable(n) {
  for (let i = 1; i <= 10; i++) {
    console.log(n + ' × ' + i + ' = ' + (n * i));
  }
}
Пример 4

10 случайных чисел без кратных 4 (continue)

Вывести ровно 10 случайных чисел из диапазона 1–20, кроме тех, которые делятся на 4. Используем while + continue.
Как это работает: количество итераций заранее неизвестно (случайные числа), поэтому берём условный цикл. При попадании числа, кратного 4, оператор continue прерывает текущую итерацию — число не попадает в результат, а цикл генерирует следующее. 
function randomNoMod4() {
  let result = [];
  while (result.length < 10) {
    let r = Math.floor(Math.random() * 20) + 1;
    if (r % 4 === 0) continue;
    result.push(r);
  }
  return result;
}

сложная

Кибербезопасность
Бинарный поиск — не только алгоритм из этой задачи. Он лежит в основе поиска по логам, анализа сигнатур и оптимизации перебора паролей при атаках. Понимание, как быстро «схлопывается» диапазон, помогает оценивать стойкость систем к перебору.
