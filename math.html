Теория

Объект Math learn.javascript.ru/number

В JavaScript для математических операций предусмотрен встроенный объект Math. Он содержит набор функций и констант, которые доступны в любой программе без подключения дополнительных библиотек.

Все функции Math принимают и возвращают числа. Особенность JavaScript: числа хранятся в двоичном виде, поэтому некоторые десятичные дроби не могут быть представлены точно. На практике это означает погрешность вычислений:

0.1 + 0.2
// 0.30000000000000004 — а не 0.3!

Именно поэтому округление — не просто удобство, а необходимость для работы с деньгами, процентами и измерениями.

Три способа округления

Ключевое различие между Math.floor, Math.round и Math.ceil — направление округления для дробных чисел:

xfloor(x)round(x)ceil(x)
4.1445
4.7455
-4.1-5-4-4
-4.7-5-5-4

Запомните правило: floor всегда идёт «к началу координатной оси слева», ceil — наоборот. Для отрицательных чисел поведение кажется «инвертированным» и это часто путает новичков.

Math.round(x) округляет по правилам арифметики: дробная часть от 0.5 и выше — вверх, ниже — вниз.

Генерация случайных чисел MDN — Math.random

Math.random() — функция, которая возвращает псевдослучайное число в диапазоне от 0 (включительно) до 1 (исключительно). Каждый вызов возвращает новое число.

Чтобы получить число в нужном диапазоне, используются формулы:

// Случайное число от 0 до max-1
Math.floor(Math.random() * max)

// Случайное число от 0 до max (включительно)
Math.floor(Math.random() * (max + 1))

// Случайное число от min до max (включительно)
Math.floor(Math.random() * (max - min + 1)) + min

Формула работает за счёт того, что Math.random() даёт дробь от 0 до 0,999... Умножение на (max - min + 1) растягивает диапазон, а Math.floor отбрасывает дробную часть — получается целое число.

Важно помнить: Math.random() — псевдослучайная, а не криптостойкая. Для задач, требующих настоящей случайности (генерация паролей, токенов), используют crypto.getRandomValues(), но для учебных задач Math.random() подходит.

Кибербезопасность
Math.random() не подходит для криптографических целей, так как её можно предсказать. Для генерации токенов, паролей и сессионных ключей в production используйте crypto.getRandomValues().

Примеры с пошаговым разбором

Пример 1

Округление чисел

Сравнить результаты Math.floor(), Math.round() и Math.ceil() для одного и того же числа. Разберем, как каждый из них работает с положительными и отрицательными числами. 
let x = 4.7;
Math.floor(x);  // 4 — вниз
Math.round(x);  // 5 — арифметическое
Math.ceil(x);   // 5 — вверх
Пример 2

Случайные числа в диапазоне

Сгенерировать 5 случайных целых чисел в заданном диапазоне. Используем Math.random() и Math.floor(). 
function randomInRange(min, max) {
  let range = max - min + 1;
  return Math.floor(Math.random() * range) + min;
}
Пример 3

Math.min, Math.max, Math.pow

Используем Math.min() для нахождения меньшего числа, Math.max() — для большего, Math.pow() — для возведения в степень. 
Math.min(10, 3);     // 3
Math.max(10, 3);     // 10
Math.pow(2, 5);      // 32
Пример 4

Модуль и квадратный корень

Используем Math.abs() для нахождения модуля и Math.sqrt() для квадратного корня. 
Math.abs(-25);       // 25
Math.sqrt(25);       // 5

Задачи для самостоятельной работы

8 задач. В каждой нужно применить математические функции в сочетании с условным оператором и/или циклами. Код задач в файл не включен — пишите всё самостоятельно.

1

Округление и сравнение

лёгкая
Запросить дробное число. Вывести его floor, ceil, round. Затем определить, какое из трёх округлённых значений находится ближе всего к исходному числу, используя Math.abs() и if.
Пояснение
Посчитайте три модуля разности: |x - floor|, |x - ceil|, |x - round|. Чем меньше разность — тем ближе результат. Сравните их через if-else if и выведите победителя. Для x = 4.7 разности будут: 0.7, 0.3, 0.3 — ближе всех ceil (0.3) и round (0.3).
2

Случайная карта

лёгкая
Сгенерировать случайное число от 1 до 52 (колода карт). Используя switch, определить масть (1–13 пики, 14–26 червы, 27–39 бубны, 40–52 трефы) и достоинство (1 — туз, 11 — валет, 12 — дама, 13 — король). Вывести название карты.
Пояснение
Сначала через switch определите масть по диапазону. Затем вычислите номер достоинства: остаток от деления на 13, где 1 — туз, 11–13 — картинки. Используйте Math.floor(Math.random() * 52) + 1 для генерации. Это классическая задача на связку switch + Math.
3

Угадай число (против компьютера)

средняя
Компьютер загадывает случайное число от 1 до 100. Пользователь вводит свои варианты, пока не угадает. После каждой попытки программа сообщает «больше» или «меньше». В конце вывести количество попыток.
Пояснение
Загадайте число: Math.floor(Math.random() * 100) + 1. Организуйте цикл do…while: ввод пользователя, проверка if (guess < target) — «больше», if (guess > target) — «меньше». Счётчик попыток увеличивайте на каждой итерации. Цикл завершается, когда guess === target.
4

Статистика случайных чисел

средняя
Сгенерировать 1000 случайных чисел от 0 до 9. Посчитать, сколько раз выпало каждая цифра. Результат выведите: ноль — 98 раз, один — 105 раз и т.д.
Пояснение
Заведите 10 переменных-счётчиков (или один массив count[10]). В цикле for 1000 раз сгенерируйте число и увеличьте соответствующий счётчик: count[digit]++. В конце выведите все счётчики. Ожидайте: каждая цифра выпадает примерно 100 раз (равномерное распределение).
5

Целочисленное деление

средняя
Запросить два числа A и B. Вывести результат деления A на B с точностью до двух знаков после запятой, используя Math.round().
Пояснение
Приём «округление до N знаков»: умножьте результат на 10 в нужной степени, округлите, разделите обратно. Для двух знаков: Math.round(result * 100) / 100. Не забудьте проверить, что B ≠ 0, через if.
6

Гипотенуза треугольника

средняя
Запросить длины двух катетов прямоугольного треугольника. Вычислить гипотенузу по теореме Пифагора (c = √(a² + b²)) через Math.sqrt() и Math.pow(). С помощью if проверьте, что катеты положительны.
Пояснение
Формула: c = Math.sqrt(Math.pow(a, 2) + Math.pow(b, 2)). Сначала проверьте if (a > 0 && b > 0) — длины сторон не могут быть отрицательными. В противном случае выведите ошибку. Округлите результат до 2–3 знаков.
7

Симуляция броска кубика

сложная
Смоделировать 1000 бросков двух шестигранных кубиков (d6). Посчитать, сколько раз выпала каждая сумма от 2 до 12.
Пояснение
Сумма двух кубиков — от 2 до 12. Заведите массив счётчиков count[13] (индексы 2–12). В цикле for 1000 раз: генерируйте два числа 1–6, складывайте, увеличивайте count[sum]++. Математическое ожидание: наибольшая вероятность у суммы 7 (6 комбинаций из 36).
8

Проверка распределения случайных чисел

сложная
Сгенерировать 10000 случайных чисел от 0 до 1 через Math.random(). Разделить диапазон [0,1) на 10 интервалов по 0.1. Посчитать, сколько чисел попало в каждый интервал. Вывести таблицу.
Пояснение
Номер интервала = Math.floor(value * 10). Например, 0.37 → 3 (интервал 0.3–0.4). Заведите массив из 10 счётчиков, заполняйте в цикле, затем выведите гистограмму. Если Math.random() корректна — в каждом интервале примерно по 1000 значений.
