Теория

Что такое массив learn.javascript.ru/array

Массив — это упорядоченная коллекция значений. В отличие от простых переменных, которые хранят одно значение, массив хранит набор значений под одним именем.

Представьте ящик с пронумерованными ячейками: каждая ячейка — это один элемент массива, а её номер — индекс.

Создать массив можно с помощью квадратных скобок:

let scores = [85, 90, 78, 92];
let names = ["Анна", "Пётр", "Мария"];
let empty = [];           // пустой массив

Массив может хранить данные любых типов — числа, строки, логические значения, а также смешанные данные:

let mixed = [12, "apple", true, 3.14, false];

В нашей практике чаще всего встречаются массивы чисел (результаты измерений, оценки, значения датчиков) и массивы строк (имена файлов, адреса, логи).

Каждый элемент массива имеет индекс — номер позиции. Нумерация начинается с 0:

//  индексы:   [0]   [1]   [2]   [3]
let arr = [10,   20,   30,   40];
arr[0];    // 10 — первый элемент
arr[2];    // 30 — третий элемент

Начинающим кажется странным, что первый элемент имеет индекс 0, а не 1. Это особенность большинства языков программирования: индекс — это смещение от начала массива. Нулевое смещение — первый элемент, смещение на 1 — второй и так далее.

Длина массива хранится в свойстве length. Последний элемент всегда имеет индекс arr.length - 1:

let arr = [10, 20, 30];
arr.length;        // 3
arr[arr.length - 1]; // 30 — последний элемент

Это свойство можно читать как обычное значение, но важно понимать: length — это не количество элементов, которые вы пересчитали вручную, а встроенное свойство, которое JavaScript автоматически поддерживает при добавлении и удалении элементов.

Важно: если обратиться к несуществующему индексу, получим undefined, а не ошибку:

let arr = [10, 20, 30];
console.log(arr[10]);  // undefined

Это поведение отличается от многих других языков, где обращение за границы вызывает исключение. В JavaScript такая запись просто вернёт undefined — что иногда приводит к неявным ошибкам, если не проверять границы индекса.

Запись и изменение элементов

Элементу массива можно присвоить новое значение, обратившись к нему по индексу:

let arr = [10, 20, 30];
arr[1] = 99;
console.log(arr);   // [10, 99, 30]

Так можно добавлять новые элементы за пределами текущей длины:

let arr = [10, 20];
arr[2] = 30;    // элемент с индексом 2 добавлен
console.log(arr.length);   // 3

Запись по индексу — базовая операция, из которой строится работа с массивами. Часто массив заполняют значениями в цикле:

let arr = [];
for (let i = 0; i < 5; i++) {
  arr[i] = i * i;   // 0, 1, 4, 9, 16
}

Массив — это объект. Поэтому при присваивании переменной передаётся ссылка, а не копия данных:

let a = [1, 2, 3];
let b = a;      // b ссылается на тот же массив
b[0] = 99;
console.log(a); // [99, 2, 3] — a тоже изменился!

Это поведение отличается от простых типов (числа, строки), где присваивание всегда копирует значение:

let x = 5;
let y = x;      // y — копия числа
y = 10;
console.log(x); // 5 — x не изменился

Если нужно получить именно копию массива, используйте slice() без аргументов или синтаксис распространения [...arr]:

let a = [1, 2, 3];
let copy = [...a];   // независимая копия
copy[0] = 99;
console.log(a);      // [1, 2, 3] — оригинал не изменился
Методы добавления и удаления

У массивов есть встроенные методы для работы с началом и концом:

МетодДействиеКуда вставляетВозвращает
arr.push(x)добавляет xв конецновую длину
arr.pop()удаляет последний элемент—удалённый элемент
arr.unshift(x)добавляет xв началоновую длину
arr.shift()удаляет первый элемент—удалённый элемент
let arr = [10, 20, 30];
arr.push(40);         // [10, 20, 30, 40]
arr.pop();            // [10, 20, 30]
arr.unshift(5);       // [5, 10, 20, 30]
arr.shift();          // [10, 20, 30]

push и pop работают быстро — это операции над концом массива. unshift и shift сдвигают все элементы и поэтому медленнее на больших массивах.

Эти методы изменяют сам массив (мутируют его), в отличие от методов вроде indexOf, которые только читают данные.

Типичный паттерн — использовать массив как «список задач»: добавляйте новые элементы через push(), обрабатывайте и удаляйте через shift(), получая эффект очереди. Или через pop() — эффект стека (как «история» действий в редакторе, где возврат к предыдущему состоянию забирает последний элемент).

Поиск в массиве

Метод indexOf(x) возвращает индекс первого вхождения элемента или -1, если элемент не найден:

let arr = [10, 20, 30, 20];
arr.indexOf(20);   // 1
arr.indexOf(99);   // -1 — не найден

Метод includes(x) возвращает true или false — есть ли элемент в массиве:

let arr = [10, 20, 30];
arr.includes(20);   // true
arr.includes(99);   // false

Важно: indexOf и includes используют строгое сравнение ===.

Поиск можно реализовать и вручную циклом — это поможет понять, как устроены методы изнутри:

let arr = [10, 20, 30];
let target = 20;
let found = -1;
for (let i = 0; i < arr.length; i++) {
  if (arr[i] === target) { found = i; break; }
}
console.log(found);   // 1

Разница между indexOf и ручным поиском: indexOf возвращает индекс первого совпадения и прекращает поиск. Если элементов с одинаковым значением несколько, то для поиска последнего придётся использовать цикл с конца.

Зачем проверять результат на -1? Потому что -1 — это «условное» значение «не найдено». Такая проверка — стандартная практика:

let arr = ["admin", "user", "guest"];
if (arr.indexOf("hacker") === -1) {
  console.log("Такого пользователя нет");
} else {
  console.log("Пользователь найден");
}
Перебор массива циклом

Самый универсальный способ пройти по всем элементам — цикл for с индексом:

let arr = [10, 20, 30];
for (let i = 0; i < arr.length; i++) {
  console.log('Индекс ' + i + ': ' + arr[i]);
}

Цикл начинается с нулевого индекса и продолжается, пока индекс меньше length. Это гарантирует, что будут обработаны все элементы.

Для обхода, когда индекс не нужен, удобнее for...of — он перебирает значения напрямую:

let arr = [10, 20, 30];
for (let value of arr) {
  console.log(value);    // 10, 20, 30
}

Выбирайте цикл по задаче: for с индексом — если индекс нужен (например, для сравнения соседних элементов); for...of — если нужно просто «взять каждое значение».

Типичный паттерн — накопление результата в отдельной переменной. Так вычисляют сумму, среднее, максимум и другие характеристики массива:

let arr = [10, 20, 30];
let sum = 0;
for (let i = 0; i < arr.length; i++) {
  sum += arr[i];
}
console.log(sum);   // 60

По этому же принципу вычисляется среднее арифметическое (sum / arr.length) и поиск максимума (переменная, которая хранит пока что наибольшее найденное значение).

Кибербезопасность
Массивы в ИБ повсюду: список IP-адресов в журнале, последовательность пакетов, набор паролей для анализа. Перебор массива циклом — базовый навык для анализа логов и обнаружения аномалий (например, подсчёт частоты запросов по каждому IP).
Типовые задачи с массивами и подводные камни

Практически любая задача на массивы сводится к одному из базовых действий:

  • Агрегация — вычислить одно значение из всех элементов: сумму, максимум, среднее.
  • Поиск — найти элемент по значению или условию.
  • Фильтрация — оставить только элементы, удовлетворяющие условию.
  • Преобразование — построить новый массив на основе старого.

Каждое из этих действий на этом этапе реализуется циклом, и это правильный способ: сначала научиться строить логику вручную, затем пользоваться готовыми методами (map, filter, reduce), которые появятся в следующих темах.

Частая ошибка: выйти за границы

Условие цикла i < arr.length важно записывать именно так, а не i <= arr.length. Во втором случае последняя итерация обратится к несуществующему индексу и получит undefined:

let arr = [10, 20, 30];
for (let i = 0; i <= arr.length; i++) {
  console.log(arr[i]);   // 10 20 30 undefined
}

Изменение длины внутри цикла

Если в цикле удалять элементы массива, длина будет меняться, и цикл с фиксированным условием будет вести себя неожиданно. Пока вы не изучаете удаление сложными методами, старайтесь не менять длину массива в процессе перебора.

Пустой массив

Если массив пуст (length = 0), цикл с условием i < 0 не выполнится ни разу — это корректное поведение. Агрегацию нужно предусмотреть: сумма пустого массива — 0, а вот среднее арифметическое (0 / 0) даст NaN, что требует проверки.

Примеры с пошаговым разбором

Пример 1

Доступ по индексу

Дан массив из пяти чисел. Получить элемент по введённому индексу. Если индекс вне диапазона — сообщить об ошибке.
Как это работает: перед обращением к элементу проверяем, что индекс находится в пределах 0 .. length-1. Это защищает от ошибок и возврата undefined. 
let arr = [10, 25, 8, 42, 17];

if (idx >= 0 && idx < arr.length) {
  console.log(arr[idx]);
} else {
  console.log("Индекс вне диапазона");
}
Пример 2

Добавление через push и pop

Добавить несколько значений в конец массива через push(), затем удалить последний элемент через pop(). Проследим, как меняется длина и содержимое массива. 
let arr = [];
arr.push(5);   // [5]
arr.push(12);  // [5, 12]
arr.push(3);   // [5, 12, 3]
arr.pop();     // [5, 12]
Пример 3

Поиск значения в массиве

Найти индекс заданного значения в массиве. Сравним ручной поиск циклом и встроенный indexOf(). 
let arr = [3, 7, 1, 9, 4];
let idx = arr.indexOf(7);   // 1
Пример 4

Сумма и среднее арифметическое

Вычислить сумму и среднее арифметическое элементов массива, используя цикл for. Проследим накопление суммы шаг за шагом. 
let arr = [3, 7, 1, 9, 4];
let sum = 0;
for (let i = 0; i < arr.length; i++) {
  sum += arr[i];
}
let avg = sum / arr.length;

Задачи для самостоятельной работы

8 задач. В каждой нужно применить массивы в сочетании с условным оператором и/или циклами. Код задач в файл не включен — пишите всё самостоятельно.

1

Сумма положительных

лёгкая
Дан массив чисел, например [3, -1, 5, -7, 2]. Найти сумму только положительных элементов. Используйте цикл for и условие if (arr[i] > 0).
Пояснение
Пройдите массив циклом, внутри проверяйте значение каждого элемента. Если оно положительное — прибавляйте к сумме. Отрицательные и нули пропускайте.
2

Максимум и минимум

лёгкая
Дан массив чисел. Найти максимальный и минимальный элемент без Math.max/Math.min — вручную циклом.
Пояснение
Примите за максимум первый элемент, затем сравнивайте с остальными: если arr[i] > max — обновляйте max. Аналогично для минимума.
3

Подсчёт чётных

лёгкая
Дан массив чисел. Посчитать, сколько в нём чётных элементов. Используйте arr[i] % 2 === 0.
Пояснение
Введите счётчик, обнулите его. В цикле проверяйте остаток от деления на 2: если 0 — увеличивайте счётчик.
4

Есть ли заданное значение

средняя
Дан массив чисел и некое значение. Определить, есть ли оно в массиве, и вывести его индекс. Реализуйте вручную (без indexOf), затем проверьте решение встроенным методом.
Пояснение
Используйте переменную found = -1. В цикле при совпадении запишите индекс и прервите цикл оператором break. Значение -1 означает «не найдено».
5

Разворот массива

средняя
Дан массив. Создать новый массив, в котором элементы расположены в обратном порядке. Реализуйте без встроенного reverse().
Пояснение
Пройтись по исходному массиву с конца и добавить элементы в новый массив через push(). Индекс с конца: arr[arr.length - 1 - i].
6

Фильтр по условию

средняя
Дан массив чисел. Создать новый массив только из элементов, которые больше заданного порога. Порог вводит пользователь.
Пояснение
В цикле проверяйте arr[i] > threshold. Если true — добавляйте элемент в новый массив через push(). В результате получите отфильтрованный массив.
7

Сдвиг элементов

сложная
Дан массив и число k. Сдвинуть элементы массива влево на k позиций (элементы в начале переходят в конец). Например, [1,2,3,4,5] при сдвиге на 2 → [3,4,5,1,2].
Пояснение
Можно в цикле k раз «сдвигать на 1»: сохранить первый элемент, переместить все остальные на позицию назад, записать сохранённый элемент в конец. Либо построить новый массив с индексами (i + k) % length.
8

Анализ лога попыток входа

сложная
Дан массив из 0 и 1 (0 — успешный вход, 1 — неудачная попытка). Найти самую длинную непрерывную серию единиц — то есть максимальное количество неудачных попыток подряд.
Пояснение
Храните текущую длину серии current и лучшую best. При встрече 1 — увеличивайте current, при встрече 0 — сбрасывайте в 0. После каждого шага сохраняйте максимум.
Кибербезопасность
Подсчёт максимальной серии неудачных попыток — это детекция брутфорс-атаки. Если серия длинная, система должна заблокировать аккаунт или IP. Та же логика используется при анализе логов SIEM.
